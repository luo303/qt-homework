# 带键盘事件的计算器

Qt Widgets 桌面计算器，使用 Qt Designer `.ui` 文件设置控件属性和网格布局。界面采用四列按键布局与浅色样式表，提供四则运算、小数、正负号、退格、清除当前输入和全部清除。

## 环境与构建

- Qt 6.9.2，包含 Qt Widgets
- CMake 3.16 或更新版本，C++17 编译器；也可以用 Qt Creator 打开 `KeyboardCalculator.pro`

命令行构建：

```sh
cmake -S . -B build
cmake --build build
```

Windows 下如有多个 Qt 安装，可在 Qt Creator 中选择 Qt 6.9.2 Kit，或向 CMake 指定对应的 `CMAKE_PREFIX_PATH`。

## 输入方式

鼠标按键和键盘都调用相同的输入函数。键盘支持数字 `0`–`9`、`.` 或小键盘小数点、`+`、`-`、`*`、`/`、`Enter`/`=`、`Backspace`、`Delete` 和 `Esc`。乘除优先于加减；同级运算按从左到右计算，不支持括号。

`CE` 清空当前输入但保留待处理运算；`C` 清除全部运算状态。计算出结果后输入数字或小数点开始新数，输入运算符则从结果继续运算。连续小数点会被忽略；连续运算符会以最后输入的运算符为准；除以零或结果超出有限数范围时显示错误，下一次数字或小数点输入会重新开始。

## 手动验证清单

以下功能验证结果记录为通过。录制视频时可按表中步骤连续演示，并将运行截图补入实验报告。

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 鼠标小数运算 | `1` `.` `2` `+` `3` `.` `4` `=` | `4.6` |
| 键盘运算 | `8` `*` `7` `Enter` | `56` |
| 重复小数点 | `1` `.` `.` `5` | `1.5` |
| 连续操作符 | `8` `+` `*` `2` `=` | `16`（第二个操作符替换第一个） |
| 输入中退格 | `1` `2` `3` `Backspace` | `12` |
| 清除后重算 | `9` `+` `C` `4` `+` `5` `=` | `9` |
| 连续运算 | `2` `+` `3` `*` `4` `=` | `14`（先乘除后加减） |
| 除以零 | `9` `/` `0` `=`，再输入 `7` | 显示除零提示，再显示 `7` |

## 状态管理

- `storedValue` 保存已完成加减部分的累计值。
- `currentTerm` 和 `currentTermSign` 保存当前乘除项及其正负号。
- `pendingOperator` 保存待处理的四则运算符。
- `waitingForOperand` 标记下一位输入应替换显示内容（如刚按下运算符或清除当前项）。
- `justEvaluated` 区分计算结果与普通输入，保证结果后输入新数会开始下一次输入。
- `errorShown` 阻止错误文字参与数值运算；重新输入数字可清除错误并开始新计算。

`enterDigit`、`inputDecimalPoint`、`enterOperator`、`calculateResult` 等函数同时服务鼠标信号和键盘事件，避免两套输入逻辑产生差异。
