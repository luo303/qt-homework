# 简易文本编辑器

实验二作业：用 Qt Widgets 做一个多窗口的文本编辑器。菜单和工具栏都用 Qt Designer 的 Action 编辑器配置，编辑区是派生于 `QPlainTextEdit` 的 `CodeEditor`（带行号），查找、替换、关于三个功能各做一个对话框。

## 环境与构建

- Qt 6.11.2（MinGW 13.1.0 64bit），包含 Qt Widgets
- CMake 3.16 或更新版本，C++17 编译器；也可以用 Qt Creator 打开 `SimpleTextEditor.pro`
- 实验指导书写的是 Qt 5.12.11，本机只装了 6.11.2，代码按 Qt 6 的接口写（`QSaveFile`、`QString::fromUtf8`、`QFontDialog::getFont` 等），功能与要求一致

命令行构建：

```sh
cmake -S . -B build
cmake --build build
```

Windows 下如果装了多个版本的 Qt，在 Qt Creator 里选 Qt 6.11.2 的 Kit，或者给 CMake 指定 `CMAKE_PREFIX_PATH`。

## 界面结构

| 区域 | 内容 |
| --- | --- |
| 菜单栏 | 文件 / 编辑 / 格式 / 查看 / 帮助，按功能分组 |
| 工具栏 | 新建、打开、保存、另存为 ǀ 撤销、恢复 ǀ 剪切、复制、粘贴 ǀ 字体、字体颜色 ǀ 自动换行、显示行号 |
| 编辑区 | 提升后的 `CodeEditor`，左侧行号栏 + 当前行高亮 |
| 状态栏 | 右侧显示 `length / lines / Ln / Col` 和作者名 |
| 对话框 | 查找、替换（非模态，开着也能改正文）、关于 |

## 功能与快捷键

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 新建 / 打开 / 保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | 未命名文件保存时自动转到“另存为” |
| 另存为 | — | 菜单“文件 → 另存为” |
| 撤销 / 恢复 | `Ctrl+Z` / `Ctrl+Shift+Z` | 无可撤销内容时菜单项是灰的 |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 没有选中内容时剪切、复制不可用；剪贴板无文本时粘贴不可用 |
| 全选 | `Ctrl+A` | |
| 查找 / 替换 | `Ctrl+F` / `Ctrl+H` | 支持区分大小写、向上/向下、连续查找（到头会绕回另一端） |
| 显示行号 | `Ctrl+L` | 复选按钮，默认打开 |
| 自动换行 | — | 菜单“格式 → 自动换行”，默认打开 |
| 字体 / 字体颜色 / 字体背景色 / 编辑器背景色 | — | 字体对话框可同时设置字体和字号；颜色作用于选中内容，没有选中时作用于后续输入 |
| 工具栏 / 状态栏显示 | — | 菜单“查看”里的两个复选项 |
| 关于 | — | 菜单“帮助 → 关于” |

计算结果之外，标题栏会跟着文件状态变：未保存的修改在文件名前加一个 `*`，保存后消失。

## 手动验证清单

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 粘贴与行号 | 粘贴 5 行文本 | 行号 1–6 正常显示，状态栏 `lines: 6` |
| 修改状态提示 | 输入任意字符 | 标题变成 `* 新建文本文件 - 简易文本编辑器` |
| 未保存关闭 | 修改内容后点关闭 | 弹出“保存 / 丢弃 / 取消” |
| 使能状态 | 不选中内容打开“编辑”菜单 | 剪切、复制为灰；选中后变为可用 |
| 连续查找 | 查找最后一个匹配词再点“查找下一个” | 回到文档开头继续，并提示“已到达文档另一端” |
| 查找未找到 | 查找一个不存在的词 | 提示“未找到「xxx」” |
| 行号开关 | `Ctrl+L` | 行号栏隐藏/显示，正文位置不跳动 |
| 打开非文本文件 | 打开含 `\0` 的文件 | 提示不是文本文件，不会把乱码塞进编辑区 |
